# SEO Text Skill — Luxury Cover Band

Цель: писать человеческие тексты для `luxuryband.ru`, которые звучат дорого и понятно, но при этом помогают поиску.

## Принцип

Не набивать страницу ключами. Каждый текст должен отвечать на реальный вопрос клиента: кто выступает, для какого события, что входит, как это выглядит, как быстро согласовать состав.

## Базовая структура страницы

1. `title`: 45-70 символов, главный запрос ближе к началу.
2. `description`: 120-160 символов, конкретная польза + формат + Москва/международные туры там, где уместно.
3. `h1`: один, человеческий, без канцелярита.
4. Первый абзац: 1-2 предложения, что получает клиент и для какого события.
5. Далее: 3-5 смысловых блоков, каждый отвечает на отдельный intent.
6. CTA: “Написать в Телеграм”, без давления.

## Тон

- Короткие фразы.
- Конкретика вместо рекламных превосходных степеней.
- Слова “премиальный”, “уникальный”, “лучший” использовать только если есть доказательство рядом.
- Подходящие слова: живой бенд, кавер-группа, программа, состав, вокалисты, welcome, банкет, танцпол, интерактив, сцена, Москва.
- Не использовать: “незабываемый праздник” без конкретики, “под ключ” в каждом абзаце, повтор одного запроса больше 2-3 раз.

## SEO-словарь по типам страниц

### Свадьба

Запросы: кавер-группа на свадьбу, живая музыка на свадьбу, первый свадебный танец, welcome на свадьбу, группа на банкет.

Человеческая формулировка: “Один состав закрывает церемонию, welcome, первый танец, банкет и ночной танцпол”.

### Корпоратив

Запросы: кавер-группа на корпоратив, живая музыка на корпоратив, группа на новогодний корпоратив, корпоративное мероприятие.

Человеческая формулировка: “Подбираем программу под аудиторию, бренд, площадку и тайминг вечера”.

### Тематические программы

Запросы: итальянская программа, французская программа, испанская программа, ретро программа, джазовая программа, рок программа.

Человеческая формулировка: “Не просто список песен, а отдельная подача: язык, костюм, пластика, интерактив и визуальный код”.

### Саксофон

Запросы: саксофонист на свадьбу, саксофонист на мероприятие, sax welcome, живая музыка на welcome.

Человеческая формулировка: “Саксофон мягко собирает атмосферу на welcome и может перейти в шоу с группой”.
